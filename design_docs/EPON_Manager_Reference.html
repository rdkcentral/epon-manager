2. Telemetry Events (T2 Markers)

All event-driven telemetry markers are reported to the RDK T2 framework. Naming convention: EPON_<CATEGORY>_<EVENT_NAME>.

Note: Periodic statistics telemetry (Section 6 in the original proposal) has been replaced by the Harvester Avro report described in Section 3.

2.1 ONU Status Events

Triggered by the HAL status_callback when the ONU registration state changes.

Event NameMeaningPriorityTrigger Frequency
EPON_ONU_LOSPhysical layer is down. No downstream optical signal detected. The ONU has lost connectivity to the OLT.CriticalOn fiber cut or OLT failure. Typically 0–2 times/day.
EPON_ONU_DOWNSTREAM_SIGNAL_DETECTEDDownstream optical signal detected but ONU is not yet registered with the OLT. Transitional state during startup or recovery.InfoDuring startup or after LOS recovery. 1–2 times per boot cycle.
EPON_ONU_REGISTRATIONONU has completed MPCP discovery and OAM negotiation. LLID-0 is online and the ONU is fully registered with the OLT.InfoTypically once per boot. May recur after LOS recovery (1–3 times/day).
EPON_ONU_DEREGISTRATIONONU has been deregistered from the OLT. LLID-0 is offline. May be OLT-initiated or due to link failure.Warning0–1 times/day normally.

2.2 Interface Link Status Events

Triggered by the HAL interface_status_callback when a Layer-2 interface (e.g., veip0) changes state.

Event NameMeaningPriorityTrigger Frequency
EPON_INTF_LINK_UPAn EPON WAN interface (e.g., veip0) is operationally up. Traffic can flow.InfoAfter ONU registration. 1–3 times/day.
EPON_INTF_LINK_DOWNAn EPON WAN interface is operationally down. No traffic.WarningOn deregistration or fiber cut. 0–2 times/day.
EPON_PHY_STATUS_UPAggregate PHY status: at least one interface is UP. WanManager notified.Info1–2 times/day.
EPON_PHY_STATUS_DOWNAggregate PHY status: all interfaces are DOWN. WanManager notified.Critical0–1 times/day.

3. Harvester Periodic Report (Avro)

All periodic statistics formerly reported as individual T2 telemetry markers have been consolidated into a single Harvester Avro report named EPONTelemetryDiagnostics. The report is generated by the stats poller at a configurable interval (default: 900 seconds / 15 minutes) and published as a binary Avro record to the Harvester pipeline.

Schema namespace: com.comcast.kestrel.odp.event
Record name: EPONTelemetryDiagnostics

3.1 Report Fields

The report contains a standard Kestrel header, CPE identification, and the EPON telemetry data payload. All data fields are nullable to handle cases where a value is unavailable.
